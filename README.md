# 2024 Chocolate Sales Performance Analysis

## Overview

Interactive sales analytics dashboard analyzing product performance, customer behavior, and regional sales trends using Power BI, SQL, and Python forecasting techniques.

---

## Tools Used

- SQL
- Power BI
- DAX
- Python

---

## Analysis Type

Descriptive Analytics

---

## Key Findings

- Ferrero leads overall branded product revenue.
- Dark Chocolate 50% is the top-selling product type.
- 50g and 100g products account for the majority of quantity sold.
- Revenue growth is driven more by premium product mix than volume increases.
- Customer preferences remain concentrated around two core products (Ferrero - Praline 50% and Mars - White 60%)

---

## Methodology

1. Collected sales data from Kaggle and cleaned/transformed it using SQL.
2. Built a relational data model and DAX measures in Power BI.
3. Developed interactive dashboards for product, customer, and regional sales analysis.
4. Conducted forecasting in Python and descriptive analytics to identify revenue trends and business insights.

---

## Outcome

Built an interactive Power BI dashboard integrating SQL, DAX, and Python forecasting to uncover product, customer, and regional sales insights and support business decision-making.
